# New Client Onboarding Checklist (Internal)

*Run through this for every new client, from proposal acceptance to kickoff. Companion to [../04_Operating_Manual/delivery-workflow.md](../04_Operating_Manual/delivery-workflow.md).*

## On proposal acceptance

- [ ] Send Terms of Engagement for signature (if not already agreed)
- [ ] Send deposit invoice (per [../02_Business_Strategy/pricing-strategy.md](../02_Business_Strategy/pricing-strategy.md) terms)
- [ ] Create client folder in file storage (see [../10_Admin/tools-and-software.md](../10_Admin/tools-and-software.md))
- [ ] Log client in CRM/tracker: business name, contact, service, price, start date

## Kickoff

- [ ] Send kickoff email confirming timeline and what's needed from the client
- [ ] Send relevant intake document (e.g. [discovery questionnaire](../05_Client_Templates/discovery-questionnaire.md))
- [ ] Schedule required sessions (discovery interview, workshop, technical access window)
- [ ] Confirm primary point of contact and any other attendees needed (e.g. IT provider)
- [ ] If technical access is required (e.g. M365 review), confirm the access method and request it

## During delivery

- [ ] Track progress against the timeline promised in the proposal
- [ ] Follow up proactively if client inputs are delayed (see [../04_Operating_Manual/delivery-workflow.md](../04_Operating_Manual/delivery-workflow.md))
- [ ] Keep working notes organised in the client folder as the engagement progresses

## Before delivery

- [ ] Run the full [report-quality-checklist.md](report-quality-checklist.md) / [../04_Operating_Manual/quality-checklist.md](../04_Operating_Manual/quality-checklist.md)
- [ ] Confirm final invoice (balance) is sent

## After delivery

- [ ] Send feedback request (see [../06_Sales_and_Marketing/follow-up-email-template.md](../06_Sales_and_Marketing/follow-up-email-template.md))
- [ ] Revoke any temporary system access granted during the engagement
- [ ] Update CRM/tracker: mark complete, log actual time spent vs. estimate
- [ ] Note any natural follow-on service to mention in future (without pushing it prematurely)
- [ ] File final deliverables in the client folder per [../04_Operating_Manual/reporting-standards.md](../04_Operating_Manual/reporting-standards.md) naming convention
- [ ] If a testimonial was offered, follow up to capture it

## Assumptions / needs founder input

- CRM/tracker tool choice — see [../10_Admin/tools-and-software.md](../10_Admin/tools-and-software.md)
