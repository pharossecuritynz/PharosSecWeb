# Report Quality Checklist (Internal)

*A condensed, printable version of [../04_Operating_Manual/quality-checklist.md](../04_Operating_Manual/quality-checklist.md) for quick reference during delivery. Use the full version for the detailed rationale behind each item.*

## Before sending any report or plan

**Accuracy**
- [ ] Every finding is traceable to actual source notes/evidence
- [ ] Nothing overstated to justify further work
- [ ] Client/business name correct throughout (no leftover template or other-client names)

**Plain English**
- [ ] Executive summary understandable with zero security background
- [ ] All acronyms defined on first use
- [ ] No fear-based language

**Structure**
- [ ] Summary first, detail after
- [ ] Consistent Now/Next/Later/Monitor priority labels
- [ ] Confidentiality footer present

**Scope**
- [ ] Matches what was proposed — no silent scope creep or gaps
- [ ] Boundaries/limitations note included

**Final polish**
- [ ] Spelling/grammar checked
- [ ] Correct file name and format
- [ ] Attachments actually attached

**The gut check:** would both the most technical and least technical reader come away with an accurate, clear understanding?

If everything above is ticked — send it. If not — fix it first, even under time pressure.
