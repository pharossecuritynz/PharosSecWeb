## Section-by-section rationale

| Section | Purpose |
|---|---|
| Header | Persistent navigation and CTA access |
| Hero | Immediate positioning + primary conversion action |
| Problem/positioning | Build empathy and relevance before pitching services |
| Services | Show the concrete range of what's on offer |
| Process | Reduce anxiety about "what happens if I engage" |
| Built for SMEs | Reinforce differentiation (right-sized, independent) |
| About/credibility | Build trust in who's behind the brand |
| Final CTA | Second, lower-friction conversion opportunity after a full scroll |
| Footer | Wayfinding and contact fallback |

## Responsive notes

- Mobile: all multi-column grids collapse to single column; header CTA shortens to "Book a review"; process steps stack vertically without the connecting line
- Tablet: services grid becomes 2 columns instead of 4

## Assumptions / needs founder input

- None — matches the already-built site. Update this wireframe if the section order or structure changes.
