# Service Catalogue

Full detail for each service lives in its own file in this folder. This page is the at-a-glance summary used for proposals, the website, and internal reference.

## Service selection guide (for discovery calls)

| If the client says... | Recommend |
|---|---|
| "We don't know where we stand" | Cyber Risk Review |
| "We're on Microsoft 365 and not sure it's set up safely" | Microsoft 365 Security Basics Review |
| "We're worried about phishing / fake invoices" | Email and Phishing Readiness |
| "We don't have a plan if something goes wrong" | Incident Readiness Workshop |
| "Our staff need better awareness" | Staff Cyber Awareness Sessions |
| "We need written policies for insurance/customers/compliance" | Security Policy and Checklist Starter Pack |
| "We've done a review, now what?" | SME Security Uplift Plan |
| "We want someone to call when questions come up" | Ongoing Cyber Advisor Support |
